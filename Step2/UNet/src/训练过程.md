# 准备过程
1. 下载 MNIST 数据集，解压后放在 `Step2/UNet/data` 目录下
2. 构建 UNet 模型 (xt, t -> ε_theta)
3. 构建时间嵌入层 (TimeEmbedding)

# 模型架构
![alt text](image.png)

- `main.py` 的训练配置使用 `BASE_CHANNELS = 96`，并显式传入 UNet；三个编码层的输出通道分别为 `192 / 384 / 768`，时间嵌入维度保持 `256`。
- 当前配置共有 `56,957,729` 个参数，约 5696 万。
- 原先基础通道为 `64` 的模型权重不能直接加载到基础通道为 `96` 的模型，需要重新训练。

# 训练过程
1. 对于每一张训练图，随机选一个 t，用数学公式得到 xt
2. 保留前向加噪时使用的标准高斯噪声 ε，作为训练目标
3. 将 xt 输入 UNet 模型，得到预测的累计噪声分布参数 ε_theta
4. 计算 MSE，更新梯度
5. 每个 epoch 的训练结束后，完整遍历一次测试集进行验证；验证时使用 `model.eval()` 和 `torch.no_grad()`，不更新参数，并报告按样本数加权的平均验证损失

# 每个 epoch 更新损失曲线
- 分别汇总当前 epoch 各训练 batch 和验证 batch 的噪声预测 MSE，按各 batch 的样本数加权，得到训练集和验证集的平均损失。
- 在同一张图中绘制训练损失和验证损失两条曲线；横轴为从 1 开始的 epoch 编号，纵轴为平均噪声 MSE。
- 每个 epoch 验证结束后，使用本次训练已完成的全部 epoch 数据覆盖更新 `Step2/UNet/outputs/TurnX/graph/loss_curve.png`。

# 采样过程
1. 随机采样一个高斯噪声图 xT
2. 将 xT 输入 UNet 模型，得到预测的累计噪声分布参数 ε_theta
3. 根据 ε_theta 还原 x0
4. 利用这里的 x0 计算后验分布 xt-1
5. 循环执行 t → t-1，直到得到 t=0 的干净状态；最后一步不再加噪声

# 每 100 次训练保存权重和去噪动图
- 按跨 epoch 累计的训练步数 `global_step`，每 100 次参数更新保存一次模型权重和一个 GIF。
- 所有输出统一由 `main.py` 的 `OUTPUT_DIR` 控制，当前为 `Turn3`；修改这一处即可切换 `TurnX`。
- 权重保存位置：`Step2/UNet/outputs/TurnX/weights/model_epoch{epoch}_step{global_step}.pth`。
- GIF 保存位置：`Step2/UNet/outputs/TurnX/gifs/denoise_epoch{epoch}_step{global_step}.gif`。
- 权重和 GIF 的文件名使用同一个从 1 开始的 epoch 编号和累计训练步数 `global_step`，便于对应检查。
- 使用当前训练 batch 的第一张图，从它的随机时间步 t 逐步采样到 0。
- 每帧标注当前 t，最终帧标注 x0 并停留 800 ms，动图循环播放。
- `main.py` 中 `GIF_FRAME_EVERY = 10` 控制每隔多少个去噪步骤保存一帧；设为 `1` 可展示每一步。无论抽帧间隔多少，所有去噪步骤都会执行，并保留起始和结束画面。
