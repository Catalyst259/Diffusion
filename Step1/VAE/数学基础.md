# Auto-Encoder
自编码器是一类自回归网络，它接收一个高维输入，将其压缩到低维空间（Latent Space）随后再从 Latent Space 重建出原始输入。自编码器的目标是学习一个有效的表示，使得输入数据可以被压缩和重建。其中， Encoder 和 Decoder 可以有多种实现方式，例如全连接网络、卷积神经网络等。自编码器的训练通常使用无监督学习方法，通过最小化输入和重建输出之间的差异来优化模型参数。
AE 衍生出了多种变体，比如 VAE，Conv-AE，Denoising AE，Sparse AE...

# PCA
PCA 是一种线性降维方法，它通过减去数据均值并计算协方差矩阵来找到数据的主成分，并进行投影。PCA 的目标是找到数据中方差最大的方向，从而实现数据的压缩和降维。PCA 在面对线性数据时有着良好的表现，但对于非线性数据，PCA 的效果可能不如自编码器等非线性方法。

# Variational-Auto-Encoder (VAE)
Auto-Encoder 只能根据输入图片重建原始图片，但是很多时候，我们想生成全新的图片，这时候事情就变得有点复杂了。

一个符合直觉的想法是在 Latent Space 中随机采样并利用训练好的 Decoder 去解析，然而，由于潜空间非常复杂，随机采样只能得到乱码。

另一种思路是获取编码后图像在潜空间内的坐标，并在它附近采样。但这也不行，因为潜空间复杂混乱的结构，即使在原图像附近采样，也可能得到 Nonsence，而如果贴着坐标点采样，得到的又是完全相同的图像，没有意义。

因此，我们需要对潜空间进行约束，使得潜空间的分布更加规则，从而使得在潜空间中采样得到的点能够生成有意义的图像。

记原始图片为 x，潜空间的坐标为 z。后验分布 p(z|x) 给出了某个潜在向量 z 由特定图像 x 生成的概率。解码器为 p(x|z)，原始图片的分布为 p(x)，潜空间的分布为 p(z)。

我们人为规定潜空间的无条件分布 p(z) 为标准正态分布 N(0,1)，即潜空间的每个维度都是独立同分布的标准正态分布。由于标准正态分布可以直接采样，p(x|z) 可以直接通过解码器生成图像。然而，p(z|x) 仍然无法简单得到。

我们依然可以假定 p(z|x) 服从高斯分布 N(μ,σ²)。即根据不同 x 的取值，潜空间的分布服从不同 μ 和 σ² 的高斯分布

到这里，我们只需要训练一个编码器来预测 μ 和 σ²，就可以得到 p(z|x) 的分布。然后我们可以从这个高斯分布中采样 z，解码器 p(x|z) 采样在潜空间向量为 z 的条件下 x 的条件概率分布，从而生成新的图像。

VAE 的损失函数分两部分：一部分用于衡量重建误差，即最终重建生成的图像与原始图像的差异，用 MSE 即可；另一部分用于衡量后验分布与先验分布（标准正态分布）的差异，通常使用 KL 散度来衡量。

总结一下：
1. VAE 输入一张图片，生成一组 μ 和 σ²，我们用 μ 和 σ² 构造后验潜空间分布 p(z|x)
2. 从 p(z|x) 中采样 z，并以 z 为条件，采样 p(x|z)，即原始图像空间，得到输出图像。
由于这里使用了两步采样，因此输出的图像具备多样性。

但是到这里问题没有解决，因为我们无法直接采样过程反向传播，无法训练编码器。为了解决这个问题，我们使用了重参数化技巧（Reparameterization Trick）。我们把随机过程提取出来封装在一个独立的随机变量 ε 中，ε 服从标准正态分布 N(0,1)，然后我们将 p(z|x) 表示为 p(z|x) = μ + σ * ε。这样，采样过程就变成了一个确定性过程，可以进行反向传播，从而训练编码器。

原始采样过程：
1. 从 N(μ,σ²) 中采样一个样本点

重参数化后的采样过程：
1. 从 N(0,1) 中采样一个样本点 ε
2. 计算 z = μ + σ * ε

VAE 网络输出三部分内容：μ、σ² 和重建图像。
损失函数会把 N(μ,σ²) 和 N(0,1) 的 KL 散度，以及原始图像和重建图像的 MSE 相加，计算梯度并更新网络参数。
损失函数是从log p(x) 的下界推导出来的，最大化下界就等价于最小化损失函数。DDPM 也是从 log p(x) 的下界推导出来的，用到了类似的思想，只是维度更多

综上，VAE 通过学习标准正态分布，得到了一个规则的潜空间，使得在潜空间中采样得到的点能够生成有意义的图像。
VAE 的弱点就是重建后的图片往往像素不高
